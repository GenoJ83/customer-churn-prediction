# Customer Churn Prediction & Retention Analytics

An end-to-end production-grade machine learning project predicting enterprise customer churn using tree-based ensembles, explainable AI (SHAP), and real-time REST inference API.

## Project Overview
Customer attrition is a major revenue threat in SaaS and telecom domains. This repository implements:
- Synthetic churn data ingestion and statistical distribution validation
- Comprehensive Exploratory Data Analysis (EDA) and cohort analysis
- Feature engineering and pipeline transforms with scikit-learn
- Baseline vs. Tuned Gradient Boosted Trees (XGBoost / LightGBM)
- SHAP (SHapley Additive exPlanations) model interpretability
- Production-ready FastAPI scoring microservice
- Containerization and CI/CD workflow
